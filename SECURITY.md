# Security

OMO is a development baseline. Keep it on loopback/private networks. Review docs/SECURITY_MODEL.md before enabling sandbox or external providers. Do not put publishing/training credentials in runtime. Do not expose arbitrary native Python, shell, user-selected URLs or public code execution.

For a suspected vulnerability, contact the repository owner privately. Do not include live credentials, user prompts or executable exploit payloads in a public issue. Public dependency advisories, test evidence and unresolved release blockers are documented; passing tests is not a claim of complete security.
